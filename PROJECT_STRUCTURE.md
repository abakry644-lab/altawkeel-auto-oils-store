# بنية مشروع التوكيل

هذا المرجع يوضح أقل عدد من الملفات التي تحتاج إلى تعديلها للحفاظ على المتجر وتطويره. الكتالوج والسلة محليان، والطلبات تصل عبر واتساب.

## الملفات الأساسية

| المسار                                       | المسؤولية                                    | متى تعدله؟                                   |
| -------------------------------------------- | -------------------------------------------- | -------------------------------------------- |
| `client/src/data/catalog.ts`                 | المنتجات والأسعار والصور والتصنيفات          | عند إضافة منتج أو تعديل سعره أو حالته.       |
| `client/src/pages/Home.tsx`                  | الصفحة الرئيسية والأقسام التسويقية           | عند تعديل العناوين أو الأقسام المعروضة.      |
| `client/src/pages/Shop.tsx`                  | قائمة المنتجات والبحث والتصفية               | عند تغيير طريقة عرض الكتالوج.                |
| `client/src/pages/ProductDetail.tsx`         | تفاصيل المنتج وزر الإضافة للسلة              | عند إضافة معلومات أو مواصفات للمنتج.         |
| `client/src/components/store/CartDrawer.tsx` | السلة ونموذج بيانات العميل                   | عند تعديل حقول الطلب أو النصوص قبل واتساب.   |
| `client/src/contexts/CartContext.tsx`        | منطق السلة المحلية وتخزينها                  | عند تعديل آلية الكمية أو إرسال الطلب.        |
| `client/src/lib/contact.ts`                  | رقم واتساب، الرسالة والتحقق من بيانات العميل | عند تعديل رقم التواصل أو صيغة الرسالة.       |
| `client/src/components/store/StoreShell.tsx` | الرأس والتذييل والتنقل                       | عند تعديل الشعار أو روابط التنقل أو التذييل. |
| `client/src/index.css`                       | الألوان، الخطوط، والحركات                    | عند تغيير الهوية البصرية العامة.             |

## مسار الطلب الحالي

> يختار العميل المنتج، ثم يضيفه إلى السلة، ويملأ الاسم والهاتف والعنوان، وبعدها تُفتح رسالة واتساب بتفاصيل الطلب. تُفرغ السلة تلقائيًا بعد فتح الرسالة.

## إضافة منتج

الدليل التفصيلي موجود في [`ADD_PRODUCTS_GUIDE.md`](./ADD_PRODUCTS_GUIDE.md). باختصار، أضف عنصرًا جديدًا إلى `LOCAL_PRODUCTS` داخل `client/src/data/catalog.ts`، وتأكد من أن `id` و`handle` فريدان وأن رابط الصورة يبدأ بـ `/manus-storage/`.

## تشغيل المشروع محليًا

```bash
pnpm install
pnpm dev
```

وللتحقق من سلامة التغييرات:

```bash
pnpm check
pnpm test
```
